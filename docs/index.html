Install on Android

1
Download the APK

Tap the Download APK button above. The latest GreenMind AI release will download from GitHub.

2
Open the downloaded file

Open app-release.apk from your browser's Downloads or your Files app.

3
Allow installation if Android asks

If Android shows a security prompt for an app from an unknown source, allow the browser or file manager to install this APK.

4
Install GreenMind AI

Tap Install and launch the app after installation completes.
